# Protocol Coreline (ProLine)

Protocol Coreline (ProLine) is a boundary-layer protocol that defines
structural transitions between symbolic intent and externally effective
state change.

The Canonical Spine defines:

- Authority state transitions
- Execution boundary semantics
- Auditability guarantees
- Interruptibility invariants

ProLine does not define:

- implementation behavior
- governance models
- identity systems
- policy logic
- agent reasoning

## Protocol Scope

ProLine operates as a neutral structural layer.

Execution environments interpret Authority according to their own
mechanisms, while ProLine governs when and how authority may cross
into externally effective action.

## Architectural Spine

The Canonical Spine represents the minimal protocol grammar.
Future drafts may introduce profiles or examples, but the spine
remains the authoritative structural reference.
